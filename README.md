# Tugas Pintar

Aplikasi To-Do List ringkas dalam Bahasa Melayu.

## Ciri
- Tambah tugasan dengan keutamaan
- Tandakan tugasan selesai
- Tapis semua / belum siap / selesai
- Padam tugasan dan tugasan selesai
- Statistik dan progress bar
- Data disimpan automatik dalam localStorage
- Responsive untuk desktop dan telefon

## Teknologi
HTML, CSS dan JavaScript vanilla — boleh terus dihoskan sebagai laman statik di Vercel.
